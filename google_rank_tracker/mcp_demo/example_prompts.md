# Example Prompts for Google Rank Tracking

Copy-paste these into your LLM client with ScrapeOps MCP configured.

## Basic Rank Check

```
Where does scrapeops.io rank for "proxy api" in the US? 
Show me the top 10 results with their positions, URLs, and titles.
Use the ScrapeOps MCP with the maps_web tool to make the google requests, set the country=us, retry the request if needed, then extract the results from the returned HTML. 
```

## Competitor Comparison

```
Compare the rankings of scrapeops.io, scraperapi.com and brightdata.com on google search for:

Create a comparison table showing who ranks better for each term.
Use the ScrapeOps MCP with the maps_web tool to make the google requests, set the country=us, retry the request if needed, then extract the results from the returned HTML. 

```
